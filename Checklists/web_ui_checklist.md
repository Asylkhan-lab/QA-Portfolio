# Web UI Checklist (Sample)

## Login / Auth
- [ ] Login with valid credentials
- [ ] Login with invalid password shows error
- [ ] Login with empty fields shows validation
- [ ] Password masked by default
- [ ] "Forgot password" link works
- [ ] Logout ends session

## Forms
- [ ] Required fields validation
- [ ] Min/max length validation
- [ ] Email format validation
- [ ] Error messages are clear and near the field
- [ ] Submit button disabled during request (if applicable)

## Cross-browser / Responsive
- [ ] Chrome latest
- [ ] Firefox latest
- [ ] Edge latest
- [ ] Mobile viewport (375px)
- [ ] Tablet viewport (768px)

## Performance / UX
- [ ] Main page loads without major layout shifts
- [ ] Click targets are not too small
- [ ] No broken images / missing icons
