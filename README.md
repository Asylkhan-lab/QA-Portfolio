# QA Portfolio (Manual QA)

This repository contains examples of my QA work:
- Test cases & checklists
- Bug reports
- API testing artifacts (Postman collections, notes)
- SQL samples

## Structure
- **Test-Cases/** — test cases in CSV/XLSX format
- **Checklists/** — checklists in Markdown
- **Bug-Reports/** — bug report samples in Markdown + CSV
- **API-Testing/** — Postman collection/environment + API test notes
- **SQL/** — example queries

## How to use
1. Open folders and view the files.
2. You can import `Test-Cases/*.csv` to Google Sheets/Excel.
3. You can import `API-Testing/Postman/*.json` into Postman.

> Tip: Replace the sample project name with a real website/app you tested and add your own findings.
